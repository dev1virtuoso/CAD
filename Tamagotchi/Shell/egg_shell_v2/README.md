# Tamagotchi 蛋形外殼 v2（按鍵直接外露、無電池）

給 `Tamagotchi1` PCB 用的兩件式蛋形外殼。**只有兩個零件**：前殼 + 背殼，
沒有按鍵柱塞、沒有任何額外小件。開孔全部由 PCB 的 Edge.Cuts 與焊盤座標生成。

| 項目 | 數值 |
|---|---|
| 外殼外形 | **82.05 × 97.28 × 17.2 mm** |
| PCB | 70.10 × 85.33 × 1.6 mm |
| 內腔 | 75.65 × 90.88 mm，板邊四周單邊間隙 **2.8 mm** |
| 前腔淨空 | **6.6 mm**（PCB 正面 → 前殼內壁 z=8.2） |
| 後腔淨空 | **5.0 mm**（PCB 背面 → 後殼內壁 z=−5.0，只走線／焊點，不放電池） |
| 殼壁 | 前 / 後各 2.0 mm，側壁最薄 2.2 mm |
| 分模面 | z = 0（PCB 背面），邊緣 R5 圓角 |
| 固定 | **3 顆 M3×12 螺絲**由背殼穿過 PCB 的 3 個 Ø3.2 孔鎖進前殼螺絲柱 |
| 零件數 | **2**（前殼、背殼） |
| 預估重量 | 約 23–27 g（PLA、3 道牆、20 % 填充） |

> v1 的「按鍵柱塞」已完全移除 —— 按鍵孔現在是直通孔，**TL3342 開關本體直接外露**，
> 手指伸進孔內按開關，不需要任何中間零件。

### 按鍵（直接外露）

```
手指
  ↓
面板 z=10.2   ┌─── Ø11 導引口 ───┐
              │   (45° 內縮)     │
前壁 z=8.2    ├─── Ø9.6 直通孔 ──┤
              │                  │   ← 前腔 6.6 mm（無任何零件）
              │      ┌────┐      │
PCB  z=1.6    │      │開關│      │   ← TL3342 4.5×5.2×0.55 直接外露
              └──────┴────┴──────┘
```

- 孔位正中開關中心，Ø9.6 讓 4.5 × 5.2 的開關完整露出，周圍看得到 PCB 表面。
- 背殼在按鍵排後面加了 **3 個 Ø5.2 支撐墊**（z 到 0.0）頂住 PCB 背面，
  按按鍵時板子不會往後彎，手感才紮實（見 `images/10_section_B-B.png`）。
- 孔壁只有 2 mm 厚（前壁），手指通過孔口後即進入空腔，**指尖可直接壓到開關**；
  Ø11 的 45° 導引口用來引導手指，也讓孔口不割手。
- 開關離面板 8 mm，建議用**食指指尖**直上直下按，不要用指甲側推。

|---|---|---|---|

## 4. 組裝順序

1. **PCB**：螢幕朝前，把 PCB 放上前殼的 3 根螺絲柱（PCB 的 3 個 Ø3.2 孔就是定位孔）。
2. **背殼**：對準前殼的對位唇緣蓋上（背殼內側的凹槽套住唇緣），確認兩片貼平。
3. **鎖螺絲**：3 顆 M3×12 從背殼沉孔鎖入，鎖到貼平即可，不要用力過度（塑膠自攻牙）。
4. 插上 USB-C 線供電（見下方注意事項）。

拆解：3 顆螺絲一鬆，背殼與 PCB 一起鬆開。

## 6. 已知限制 / 設計假設

1. **USB-C 插頭與 PCB 邊緣（重要）**
   這顆 ESP32-C3 SuperMini 的 USB-C 在板子**內部**（離蛋形板邊 12 mm、離殼外表面 18 mm），
   所以我把側壁開口做成 12.4 × 6.6，讓插頭外模整段伸進殼內。
   **但請注意**：USB-C 插頭外模約 6.4 mm 高，插到底時它的底緣會比 PCB 上表面低約 0.8 mm，
   若模組是「貼平」焊在板面上，外模會先撞到 PCB 的板邊，插頭就推不到底。
   實際做法（任選一）：
   - 插頭**微微向上翹約 4°** 再推入（外模就會跨過 PCB 邊緣），插好後不要拔；
   - 或把 ESP32 模組**用 2.54 mm 排針座／墊高 ≥ 1 mm** 焊接，USB 接口就會抬高，外模自然跨得過；
   - 或用**細身（外模 ≤ 4.9 mm 高）的 USB-C 線**。
   這條線是永久供電線，插好後留在殼上即可。

2. **沒有電池**
   依你的說明，PCB 沒有電池、也沒有充電模組，全靠 USB-C 直接供電，
   所以後殼只留 5.0 mm 的走線／焊點空間，外殼總厚度從 20.2 mm 降到 **17.2 mm**。
   若之後要加鋰電池（402030 之類 4 mm 厚），把 `Z_BACK` 改成 −10.0、`Z_BCEIL` 改成 −8.0 即可回到厚版。

3. **螢幕窗公差**
   0.96" 4-pin SSD1306 的玻璃黏貼位置各家差 ±1 mm，窗口 24.0 × 14.2 已大於 AA（21.744 × 10.864）約
   1.1 / 1.7 mm，**任何常見版本都不會切到顯示區**，但黑邊可能不完全對稱。
   若你的模組偏一邊，告訴我偏移量我改一版。

4. **螢幕／ESP32 模組高度**
   以「4 pin 直焊、模組 PCB 底面離板 2.54 mm」估算：螢幕玻璃頂面 ≈ +4.94 mm（前腔餘 1.66 mm）。
   若用 8.5 mm 高的母座，模組會頂到前殼，需要把 `Z_FRONT / Z_FCEIL` 加大。

5. `assets/notes.txt` 提到的 TP4056、SPDT 電源開關（SW5）都不在 PCB 上，所以沒有對應開孔。
   要加開關孔請給我型號與位置。

## 7. 如何修改

`src/build_shell.py` 開頭參數：

```python
OUT_OFF = 6.0     # 外殼外輪廓 = PCB 外擴 6.0
CAV_OFF = 2.8     # 內腔 = PCB 外擴 2.8
Z_FRONT = 10.2    # 前表面
Z_FCEIL = 8.2     # 前腔頂
Z_BACK  = -7.0    # 後表面（改 -10.0 可回到有電池空間的厚版）
Z_BCEIL = -5.0    # 後腔頂
EDGE_F  = 5.0     # 前緣 R 角
EDGE_B  = 5.0     # 後緣 R 角
```

按鍵孔參數在 `cuts` 區塊：

```python
for bx, by in buttons:
    cuts.append(cyl(4.8, ...))                                   # Ø9.6 直通孔
    cuts.append(Part.makeCone(4.8, 5.5, 0.7, ...))               # Ø11 導引口
```

在專案根目錄重跑（需要 FreeCAD 1.0 的 `freecadcmd`）：

```bash
freecadcmd src/build_profile.py   # 換 PCB 時才需要
freecadcmd src/build_shell.py     # 讀 src/profile.json，輸出到 work/out
```

## 8. 已做的驗證

* 前殼 ∩ PCB = 0 mm³、背殼 ∩ PCB = 0 mm³（僅背殼壓板柱 0.05 mm 夾持預壓）。
* 所有元件（ESP32、螢幕、4 開關、LED、被動元件）與前／後殼干涉量 = 0 mm³。
* 前殼 ∩ 背殼 = 0 mm³（分模面只接觸、不重疊）。
* 兩件 STL 皆為封閉流形。
* 按鍵排後方 3 個 Ø5.2 支撐墊頂在 PCB 背面（間隙 0），按鍵時 PCB 不會彎。
* 開孔對位（`images/08_fit_map.png`）：螢幕窗、4 按鍵、LED、3 螺絲、USB-C 全部疊在 PCB 實際位置上。
