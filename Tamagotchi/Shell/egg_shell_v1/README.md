# Tamagotchi 蛋形外殼 v1

給 `Tamagotchi1` PCB（凱德 KiCad 專案 `PCB/Tamagotchi.kicad_pcb`）用的兩件式蛋形外殼，
直接由 PCB 的 Edge.Cuts 輪廓與各零件座標生成，全部開孔都對位到實際焊盤位置。

| 項目 | 數值 |
|---|---|
| 外殼外形 | **82.05 × 97.28 × 20.2 mm** |
| PCB | 70.10 × 85.33 × 1.6 mm（Edge.Cuts 實測 70.05 × 85.29，平滑後誤差 < 0.06） |
| 內腔 | 75.65 × 90.88 mm，板邊四周單邊間隙 **2.8 mm** |
| 前腔淨空 | **6.6 mm**（PCB 正面 → 前殼內壁 8.2 mm） |
| 後腔淨空 | **8.0 mm**（PCB 背面 → 後殼內壁 −8.0 mm） |
| 殼壁 | 前/後各 2.0 mm，側壁最薄處 2.2 mm |
| 分模面 | z = 0（PCB 背面），邊緣 R5 圓角 |
| 固定方式 | **3 顆 M3×16 螺絲**由背殼穿過 PCB 的 3 個 Ø3.2 孔鎖入前殼螺絲柱 |
| 預估重量 | 約 25–30 g（PLA、3 道牆、20 % 填充） |

```

├─ STEP/                      SolidWorks / Fusion / FreeCAD 可編輯曲面
│  ├─ front_cover.step
│  ├─ back_cover.step
│  ├─ buttons.step
│  └─ assembly_with_pcb_mock.step   含 PCB 與元件簡化模型的組合件
├─ images/                    1 前視 2 後視 3 側面 USB 4 爆炸 5/6 內腔 7 剖面 8 開孔對位 9 按鍵柱塞
└─ src/                       生成用腳本（FreeCAD 1.0 Part API + 參數表）
   ├─ parse_pcb.py            解析 KiCad PCB
   ├─ build_profile.py        取 Edge.Cuts 三次貝茲 → 平滑 → 外擴輪廓
   ├─ build_shell.py          ★ 主要建模腳本（所有尺寸參數都在最上面）
   └─ profile.json            輪廓控制點（可重現）
```

所有 STL 都已驗證為 **封閉流形（watertight / manifold）**，每條邊剛好被 2 個三角面共用。

## 2. 開孔與配合表

| 位置 | PCB 座標 (mm) | 外殼開孔 | 說明 |
|---|---|---|---|
| M3 固定孔 ×3 | (145.288, 65.024) / (117.348, 96.012) / (175.768, 113.792) | 螺絲柱 Ø6.4，M3 自攻底孔 Ø2.6 × 5.8 深 | PCB 孔 Ø3.2，背殼壓板柱頂在 z=+0.05 夾住 PCB |
| 螢幕 | 中心 (144.526, 102.50) | 窗口 **24.0 × 14.2**（內側斜邊 25.4 × 15.6）＋ 27.5 × 18.5 × 0.8 沉台 | 0.96" SSD1306 4-pin，AA 區 21.744 × 10.864 |
| 按鍵 ×4 | x = 123.444 / 137.668 / 153.518 / 169.164 ，y = 123.952 | Ø4.6 通孔 ＋ Ø7.0 × 0.8 指窩 | TL3342（4.5×5.2×0.55）；柱塞內側 Ø7.6 法蘭止擋在前殼頂面，不會掉出 |
| LED | (145.288, 122.936) | Ø2.6 通孔 ＋ Ø4.4 × 0.6 沉孔 | 內側 Ø5.4 遮光導光柱，距 LED 1.0 mm |
| USB-C 充電 | 連接器面 x≈132.78、中心 y = 78.23、z 2.95–5.17 | 側壁開口 **12.4 × 6.6**，中心 z ≈ 4.2 | 見下方「已知限制 1」 |
| 分模 | — | 前殼下緣 0.85 mm 唇緣插入背殼內側凹槽 | 對位＋遮光；徑向間隙 0.4 mm、軸向 0.05 mm |

**按鍵柱塞**（另印 4 顆，`03_buttons_x4.stl`）：
按壓面 Ø4.4（組好後在指窩內、比面板低 0.3 mm）→ 軸 Ø4.4 穿過 Ø4.6 孔 →
內側法蘭 Ø7.6 × 0.6（止擋在前殼內頂面 z = 8.2）→ 觸頭 Ø2.2 × 5.2，尖端在 z = 2.35。
開關致動器頂面 ≈ 2.15，所以**預留 0.2 mm 虛位 + 0.2 mm 行程**；
彈簧回彈時法蘭頂到殼頂，柱塞不會掉出（由內側放入，先裝柱塞再放 PCB）。

## 4. 組裝順序

1. **按鍵柱塞**：前殼面板朝下放，從**內側**把 4 顆柱塞的軸穿進 Ø4.6 孔（法蘭留在殼內）。此時柱塞會鬆動，正常。
2. **PCB**：螢幕朝前，把 PCB 放上前殼的 3 根螺絲柱；PCB 的 3 個 Ø3.2 孔即定位孔，2.8 mm 四周間隙讓板子好放。
3. **背殼**：把背殼對準前殼的對位唇緣蓋上（背殼內側朝上、和前殼的凹槽對齊），確認兩片貼平、沒有高低差。
4. **鎖螺絲**：3 顆 M3×16 從背殼沉頭孔鎖入，**不要過度鎖緊**（螺絲柱是塑膠自攻牙，鎖到貼平即可）。鎖緊時會同時夾住 PCB。
5. 螢幕模組用 4 pin 排針焊在 U2（GND/VCC/SCL/SDA）。

拆解只要反過來：3 顆螺絲一鬆，背殼與 PCB 一起鬆開。

## 5. 3D 打印建議

| 項目 | 建議 |
|---|---|
| 層高 | 0.16–0.2 mm |
| 牆數 | 3 道（1.2 mm） |
| 填充 | 20–30 %（gyroid） |
| 材料 | PLA / PETG；**前殼用黑色**可減少螢幕漏光 |
| 前殼擺放 | **前表面貼床**（z=10.2 面朝下），內腔朝上 → 3 根螺絲柱與 LED 導光柱都是往上生長的柱體，不需支撐 |
| 前殼支撐 | 只有 **USB-C 開口上緣 12.4 mm 的橋接**，建議在該處開支撐（或接受輕微垂絲，之後修整） |
| 背殼擺放 | 外表面貼床，3 根壓板柱朝上，免支撐 |
| 按鍵柱塞 | **按壓面朝下**（STL 已排好，底面是 Ø4.4 按壓面），法蘭的 1.6 mm 環形外伸可直接橋接；免支撐 |
| 公差 | Ø4.4 軸 vs Ø4.6 孔（0.1 mm 單邊）；若孔太緊，把前殼或柱塞做 0.1 mm 水平補償 |

## 6. 已知限制 / 設計假設

1. **USB-C 充電位置（重要）**
   ESP32-C3 SuperMini 的 USB-C 在 PCB 上的位置是 x ≈ 132.8–140.1、y ≈ 73.8–82.7，
   **離蛋形板邊還有 12 mm、離外殼外表面約 18 mm**——因為模組是放在板子中上方，不是貼板邊。
   為了讓插頭真的插得到，側壁開口做成 12.4 × 6.6 mm，讓 USB-C 插頭的外模（約 12 × 6.5 mm）
   可以整段伸進殼內 10 mm 左右，金屬頭才碰得到連接器。
   - 實務上請用**細身/短身 USB-C 線**，或殼內放一條 **USB-C 公-母延長線**固定在開口處（最穩）。
   - 下一版 PCB 若把 ESP32 移到板邊（USB 朝外），就可以改成 9.2 × 3.6 mm 的標準小孔。

2. **螢幕窗公差**
   0.96" 4-pin SSD1306 模組的玻璃在 27.3 × 27.8 的板上的黏貼位置，各家有 ±1 mm 差異。
   窗口 24.0 × 14.2 已大於 AA（21.744 × 10.864）約 1.1 / 1.7 mm，**任何常見版本都不會切到顯示區**，
   但黑色邊框寬度可能左右/上下不完全對稱。若你的模組偏一邊，告訴我實際偏移量，我 5 分鐘內改一版。

3. **螢幕模組高度**
   以「4 pin 排針直焊」估算（模組 PCB 底面高 2.54 mm、玻璃頂面 ≈ 板面 +4.94 mm），
   前腔 6.6 mm 讓上方還餘 **1.66 mm**。
   若你用 8.5 mm 高的母座（可換模組），模組頂面會到 +11 mm，**會頂到前殼**，需要把 `Z_FRONT / Z_FCEIL` 加大。

4. **電池 / TP4056 / SW5**
   PCB 上沒有這三個東西（`assets/notes.txt` 說明是外接模組），所以沒有對應開孔。
   後腔 8.0 mm 深（75 × 90 mm 面積）可以平放一片 4 mm 厚鋰電池（402030 之類）用雙面膠固定，
   或放 TP4056 模組。若要把電源開關（SW5）開在殼上，把開關型號與希望的位置給我，我加孔。

5. 按鍵柱塞是另印件（活動件），由內側放入、靠內側法蘭止擋，不會掉出；按壓面 Ø4.4 比經典他媽哥池的按鍵略小（受 PCB 上 4.5 × 5.2 mm 的 TL3342 與殼厚限制）。

## 7. 如何修改

`src/build_shell.py` 開頭就是一整塊參數：

```python
OUT_OFF = 6.0     # 外殼外輪廓 = PCB 外擴 6.0（改這個會整體變胖/變瘦）
CAV_OFF = 2.8     # 內腔 = PCB 外擴 2.8（板邊間隙）
Z_FRONT = 10.2    # 前表面
Z_FCEIL = 8.2     # 前腔頂（= Z_FRONT - 2.0）
Z_BACK  = -10.0   # 後表面
Z_BCEIL = -8.0    # 後腔頂
EDGE_F  = 5.0     # 前緣 R 角
EDGE_B  = 5.0     # 後緣 R 角
POST_R  = 3.2     # 螺絲柱半徑
...
```

改完後在**專案根目錄**重跑（需要 FreeCAD 1.0 的 `freecadcmd`）：

```bash
freecadcmd src/build_profile.py   # 只在換 PCB 時需要（讀 PCB/*.kicad_pcb）
freecadcmd src/build_shell.py     # 讀 src/profile.json，輸出 STL/STEP 到 work/out
```

> `build_profile.py` 裡的 PCB 路徑是相對專案根目錄寫死的，換位置時改一下 `open('PCB/Tamagotchi.kicad_pcb')` 即可。

## 8. 已做的驗證

* 前殼 ∩ PCB = 0 mm³、背殼 ∩ PCB = 0 mm³（只有 0.05 mm 的夾持預壓），元件與殼體零干涉。
* 按鍵柱塞：Ø4.4 軸對 Ø4.6 孔、法蘭 Ø7.6 大於孔徑（不會掉出）、觸頭距開關 0.2 mm。
* 前殼 ∩ 背殼 = 0 mm³（分模面只接觸、不重疊）。
* 三件 STL 皆為封閉流形，可切片。
* 開孔對位（`images/08_fit_map.png`）：螢幕窗、4 按鍵、LED、3 螺絲、USB-C 全部疊在 PCB 實際焊盤上。
