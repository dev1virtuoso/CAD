# Tamagotchi 蛋形外殼 v3 — 卡扣版（免螺絲）

給 `Tamagotchi1` PCB 用的兩件式蛋形外殼。**只有 2 個零件、完全不用螺絲**：
前後殼用 4 個 L 形卡扣咬合，PCB 直接壓在 3 支「劈開式」卡扣柱上。
開孔全部由 PCB 的 Edge.Cuts 與焊盤座標生成。

| 項目 | 數值 |
|---|---|
| 外殼外形 | **82.05 × 97.28 × 19.3 mm** |
| PCB | 70.10 × 85.33 × 1.6 mm |
| 內腔 | 75.65 × 90.88 mm，板邊單邊間隙 **2.8 mm** |
| 前腔淨空 | **8.7 mm**（PCB 正面 → 前殼內壁 z = 10.3；上一版只有 6.6） |
| 後腔淨空 | **5.0 mm**（只走線／焊點，不放電池） |
| 殼壁 | 前 / 後各 2.0 mm |
| 分模面 | z = 0，邊緣 R5 圓角 ＋ 兩邊各 0.4 mm 倒角（接縫成一條 0.8 mm 陰影線） |
| 固定 | **免螺絲**：4 個卡扣 ＋ 3 個 PCB 卡扣柱 |
| 零件數 | **2** |

## 1. 這一版改了什麼

| 你要求的 | 做法 |
|---|---|
| 修 LED／按鍵那 0.54 mm 薄筋 | 按鍵導引口由 φ11 縮到 **φ10.4**、LED 取消 φ3.6 沉孔只留 **φ2.4** 通孔 → 最薄處由 0.54 mm 變成 **1.29 mm** |
| USB 線應力消除 | 開口兩側加 **2 個束線孔（2.4 × 3.2 mm）**，用 2.5 mm 尼龍束線帶穿過去把線綁在外殼上；拉扯力不會傳到 USB 座 |
| 接縫倒角 | 前後殼分模邊各倒 **0.4 mm**，接縫成一條乾淨的 0.8 mm V 形陰影線，打印公差看不出階梯 |
| 加大 ESP 高度、USB 不卡 | 前表面由 10.2 → **12.3 mm**（前腔 6.6 → **8.7 mm**），USB 開口跟著移到插頭的實際高度（中心 z ≈ 6.56） |
| 不用螺絲、改卡扣 | 前後殼 **4 個 L 形卡扣**（鉤 + 內壁凹槽）；PCB 用 **3 支劈開式卡扣柱**，直接壓進去 |

## 3. 卡扣怎麼用

### 前後殼（4 個卡扣）
- 背殼邊緣有 **4 個 L 形鉤**（位置：蛋的上下左右四個極點），鉤的腳黏在背殼 rim 上、臂伸進前殼內腔，頂端的倒鉤卡進前殼內壁的 **凹槽（0.6 mm 深、1.0 mm 高）**。
- 關：對準後直接壓下去，「啪」一聲到底。
- 開：從接縫的 V 形溝用指甲/塑膠撬片輕輕撬開即可（不要用金屬螺絲刀，會刮傷）。
- 咬合量 0.45 mm、倒鉤下方是 15° 防脫面、上方 36° 導入斜面。

### PCB（3 支劈開式卡扣柱）
- 柱身 φ6.4 從前殼頂垂下，柱端有 **φ3.1 劈開銷 + φ3.7 倒鉤**。
- PCB 直接從後面壓上 3 支銷 → 倒鉤穿過 PCB 的 φ3.2 孔後彈開、卡住 PCB 背面。
- 一次壓到底，不用工具；拆的時候用細鉗夾住銷頭拉出（或直接連殼一起換）。

## 5. 組裝

1. 把 PCB 對準 3 支卡扣銷，**螢幕朝前**，平均用力壓到底（會聽到 3 下「啪」）。
2. 插上 USB-C 線，把線整理好、用束線帶穿過兩個束線孔綁緊（應力消除）。
3. 背殼對準 4 個卡扣位置，壓合到底。
4. 要打開：從側面接縫的 V 形溝撬開。

## 6. 打印建議

| 項目 | 建議 |
|---|---|
| 層高 / 牆 / 填充 | 0.16–0.2 mm；3 道牆；20–30 % gyroid |
| 材料 | PLA 或 PETG；**前殼用黑色**遮光。**PETG 的卡扣壽命比 PLA 好**（PLA 卡扣拆 20–30 次後會鬆） |
| 前殼擺放 | 前表面貼床（z = 12.3 面朝下、內腔朝上）→ 3 支卡扣銷、卡扣凹槽都是垂直牆，免支撐 |
| 前殼支撐 | USB-C 開口上緣與束線孔上方為橋接，建議局部加支撐（或用小橋接設定） |
| 背殼擺放 | 外面貼床，4 個卡扣鉤朝上，免支撐 |
| 公差 | 卡扣咬合 0.45 mm；如果太緊，把背殼的鉤用砂紙輕磨 0.1 mm；太鬆就在鉤的防脫面貼一層膠帶 |
| 翹曲 | 兩件第一層都是 82 × 97 大平面 → 建議加 brim（3–5 mm） |

## 7. 已知限制（請務必看）

1. **ESP 墊高高度是我假設的 2.5 mm**（2.54 mm 排針直接焊在板面）。
   前腔 8.7 mm 可以容納 **模組墊高 ≤ 4.1 mm**（模組頂面到板面 3.57 mm + 墊高）。
   - 若你用 **8.5 mm 排母**（可換模組），模組頂面會到 13.7 mm，**這個殼裝不下** → 告訴我，我做高版（前表面 ~16.5 mm），但按鍵就要改回有中間件的方案。
   - 換句話說：**免螺絲 + 按鍵直接外露 + 很長的腳** 三者不能同時成立（腳越長，前殼越厚，手指就越按不到開關）。目前是「腳 2.5 mm」的平衡點。

2. **按鍵要伸入 10.15 mm**（上一版 8.05 mm，因為前殼加了 2.1 mm）。
   孔 φ9.6 + φ10.4 導引口，指尖可穿過 2 mm 前壁進入空腔按到開關，但**深度增加了**，建議用食指指尖直上直下按。
   如果覺得太深，可以回到「腳 0 mm + 前腔 8.7」的版本（按鍵 10.15 → 8.7 mm）——把 `ESP_STANDOFF` 改 0 就好。

3. **USB-C 插頭**：插頭軸心在 z ≈ 6.56，外模（6.4 高）佔 z 3.36–9.76，離前殼內壁還有 0.54 mm。
   因為模組墊高了，**插頭外模不會再撞到 PCB 邊緣**（上一版的主要問題已解決）。
   仍建議用外模 ≤ 6.4 mm 的線，插好後用束線帶固定。

4. **卡扣是活動件**：PLA 拆 20–30 次後會鬆，PETG 更耐用。鬆了就貼膠帶或點一滴膠。
   卡扣鉤只有 1.2 mm 厚，**不要用金屬工具硬撬**。

5. **PCB 用卡扣銷固定**：PCB 厚度公差 1.6 ± 0.1 mm 不影響（倒鉤有 0.05 mm 預壓）；
   但卡扣銷是 φ3.1、PCB 孔 φ3.2，如果 PCB 孔位有偏差 > 0.2 mm 會壓不進去 → 先確認 3 個孔的位置。

6. 螢幕窗位置仍以 AA 中心 y ≈ 102.5 假設（±1 mm 容差）；你的模組若偏一邊告訴我。

## 8. 參數

`src/build_shell.py`：

```python
Z_FRONT = 12.3     # 前表面（改這個 = 改 ESP 空間，也改按鍵深度）
Z_FCEIL = 10.3     # 前腔頂  = Z_FRONT - 2.0
Z_BACK  = -7.0     # 後表面
Z_BCEIL = -5.0     # 後腔頂  = Z_BACK + 2.0
ESP_STANDOFF = 2.5 # 假設的模組墊高 → 決定 USB 開口高度
SEAM_CH = 0.4      # 接縫倒角
```

卡扣參數在 `PROF`（L 形鉤的剖面）與 `CLEAR`／`ARM_W`；按鍵孔在 `cuts` 區塊。

## 9. 已做的驗證

* 前殼 ∩ PCB = 0 mm³、背殼 ∩ PCB = 0 mm³。
* 所有元件（ESP、螢幕、4 開關、LED、被動件）與前／後殼干涉 = 0 mm³。
* 前殼 ∩ 背殼 = 0.34 mm³（卡扣的微量干涉，實物上等於「緊配」）。
* 兩件都是**單一、封閉流形實體**。
* 卡扣對位實測：鉤的臂在前殼內腔（間隙 0.2 mm）、倒鉤在前殼凹槽內（咬合 0.45 mm）、鉤腳與背殼 rim 熔接成一體。
* 按鍵／LED 之間最薄處實測 **1.29 mm**（原本 0.54 mm）。
